# PolyAgent 🤖

Autonomous Polymarket trading bot powered by Claude AI. Scans markets every 5 minutes, analyzes with AI, places trades, and learns from outcomes to improve over time.

## How it works

1. **Scans** Polymarket for quality markets (filtered by volume + liquidity)
2. **Analyzes** each market using Claude AI
3. **Places trades** when confidence exceeds the learned threshold
4. **Resolves** settled markets and records outcomes
5. **Learns** — every 10 cycles, Claude reviews performance and adjusts strategy

---

## Deploy to Railway (5 minutes)

### Step 1 — Create a GitHub repo
1. Go to github.com → New repository → name it `polyagent`
2. Upload all these files to the repo

### Step 2 — Deploy on Railway
1. Go to [railway.app](https://railway.app) and sign up (free)
2. Click **"New Project"** → **"Deploy from GitHub repo"**
3. Select your `polyagent` repo
4. Railway will auto-detect Python and deploy

### Step 3 — Set environment variables
In Railway dashboard → your project → **Variables**, add:

| Variable | Value |
|---|---|
| `WALLET_ADDRESS` | `0xd45996A1d51A0C478cb499b1bc24386734000C9f` |
| `POLYMARKET_API_KEY` | your Polymarket API key |
| `ANTHROPIC_API_KEY` | your Anthropic API key |
| `PAPER_MODE` | `true` (start here!) |
| `MAX_TRADE_SIZE` | `10` |
| `MAX_OPEN_POSITIONS` | `5` |
| `SCAN_INTERVAL_SECS` | `300` |

### Step 4 — Watch it run
- Railway dashboard → your project → **Logs**
- You'll see the agent scanning and analyzing markets every 5 minutes

### Step 5 — Go live
Once you're happy with paper trade performance (check win rate after ~20 trades):
- Change `PAPER_MODE` to `false`
- The agent will start placing real trades

## Safety features
- **Paper mode** by default — no real money until you flip the switch
- **Max open positions** cap — never overexposed
- **Confidence thresholds** — only trades high-conviction signals
- **Self-learning** — raises thresholds in losing categories automatically
- **Liquidity filter** — skips illiquid markets you can't exit
